## Descripción general

Plantilla Gob bo es una página web informativa elaborada como tema para el CMS [Drupal](https://new.drupal.org/download).
                                                                     
## Tecnologías

| Tecnológia                                      | Descripción                       |
| ----------------------------------------------- | --------------------------------- |
| [MariaDB](https://mariadb.org/)                 | Gestor de base de datos.          |
| [PHP](https://www.php.net/downloads.php)        | Lenguaje de programación.         |
| [Drupal (10.3)](https://new.drupal.org/download) | Sistema de gestión de contenidos. |
| [Leaflet](https://leafletjs.com/)               | Biblioteca javascript para mapas. |

## Recursos, herramientas y servicios externos

| Tecnológia                                   | Descripción                                              |
| -------------------------------------------- | -------------------------------------------------------- |
| [Sitemap](https://www.drupal.org/project/sitemap) | Plugin para crear el mapa de sitio |
